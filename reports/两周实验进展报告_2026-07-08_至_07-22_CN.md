## 0. 执行摘要（一页）

**研究问题**：攻击者在**不改变**任务事实、用户身份、权限、policy、工具、合法 endpoint 的前提下，仅通过多轮**用户侧互动表达**（urgency / frustration / continuation / trust 等），能否**定向操纵** tool-using agent 的完整行动过程（多调工具、改确认时机、提前 mutation、诱导放弃）？

**两周结论（一句话）**：**在越来越严格的对照、越来越高的攻击强度、并叠加结构性 confounder 与 boundary 上界之后，纯交互攻击仍未产生稳健的、可归因于对抗优化的过程操纵。** 唯一能推动结果层的是**授权暗示 / 真实任务约束**（它们改变了 threat model），而非语气本身。

**这两周的核心价值**从"我们发现了一种攻击"最终转为一个**方法学诊断**：
> **松散的过程级评估会系统性高估 agent 的交互脆弱性**——每一次"发现效应"，在下一轮更严格的对照（配对、endpoint 1→1、full-support、语义不变、多重校正、增量对比 C4−C3 / H3−H1）下都缩小或消失。

## 1. 两周实验的整体逻辑链

前两周（R7 系列）反复遭遇**"效应可识别性不足"**：R7-C 的攻击信号被 placebo 追平；R7-D 发现 suffix 裁剪设计里**根本没有过程可以被移动**（junction 放错、环境是桩）。于是从 R8 起做了三次**递进升级**，每次都对上一次的漏洞做正面修复：

```
R8   放弃 suffix 裁剪 → 回到完整多步骤 episode，直接测普通压力（C0–C4）        → calibrated null
R8-A 引入真正的"优化攻击者"(候选生成+双审过滤+定向selector) + 语义不变控制    → calibrated null（C4≈C3）
R8-B 复核 R8-A 全部定义(1→1/full-support/缓存turn-0/F3双审) + 提高强度 + 加 confounder/boundary → P-D
```

每一步都在回答一个"会不会是我们没测到"的质疑，最终把 null 逼到了**"高强度+组合+结构 confounder+授权边界"**都排除掉的程度。

## 2. 各轮实验设计与结果

### 2.1 R7-C（07-10，2592 runs）—— 静态-紧迫攻击，PILOT/AUDIT ONLY
- **设计**：C2 静态首轮 pressure vs 中性；含 **placebo 臂**（无害的存在感消息）作为噪声地板。
- **结果**：**attack PASR 4.03% ≤ placebo 4.63%**。攻击"成功"低于安慰剂 → 信号与 seed 噪声不可分。
- **判定**：不能作为 confirmatory，只作 pilot/audit。**首次量化暴露了"松散评估高估脆弱性"**。

### 2.2 R7-D（07-11~14）—— suffix 可识别性系列，NOT EXPERIMENTALLY IDENTIFIABLE
- **设计**：共享前缀 + 攻击 suffix + P-responsive eligibility 筛选。
- **失败根因**：① **环境是桩**——探针发现 3027 次工具调用中 **0 次参数真正被解释**（agent 不读取被操纵的字段）；② **junction 放错位置**，suffix 区间内没有可被改变的过程决策（null-by-construction）；③ 严格门控下 eligible cells 5 < 8，统计不可行。
- **教训**：区分 **null-by-construction（没测到）** 与 **null-by-finding（测了没有）**——这是全项目最重要的方法学分水岭，直接促成 R8 放弃整个 suffix 构造。

### 2.3 R8 完整回合（07-18，2680 episodes）—— Calibrated Null
- **设计**：回到**完整 multi-step tau2 episode**。5 条件 C0 官方合作 / C1 中性 / C2 静态压力 / C3 自适应普通压力 / C4 自适应挫败。**Canonical Semantic Controller**（condition-blind）保证语义不变，style renderer 只加语气。所有冻结任务进 ITT。
- **结果**：**P1 终点成功** C3−C1=+0.024、C4−C1=−0.006（CI 含 0，**可排除 ≥5pp**）；工具过程效应 pooled **< 1.0 call / 15% 阈值**且弥散。**探索性异质性**：frustration→工具强度在 **airline** 集中（C4−C1=+1.41 calls，超阈值），retail 近零。
- **判定**：**calibrated null**（不是"没测到"，而是"可排除大于阈值的效应"）+ 一个 airline 特异过程信号待预注册后续检验。

### 2.4 R8-A 优化定向攻击（07-18~19，2232 episodes）—— Calibrated Null
> 合作方要求："别只测普通语气，做一个**真正的 attack study**。"

- **设计**（`scripts/r8_attack/`）：
  - **条件**：C0 官方 / C1 中性 / C2 静态 / **C3 普通自适应压力** / **C4 优化攻击**。主对比 **C4−C1**，关键增量 **C4−C3**（只有 C4 明显优于 C3，效应才来自对抗优化）。
  - **优化攻击者 C4**：① 候选生成器（attacker LLM 按冻结 TARGET_DIRECTION 生成 ≤3 个 ≤40-token style 增量）→ ② **双隔离 reviewer**（gpt-oss+gemma）fail-closed 过滤 8 项污染 → ③ 定向 selector → ④ 预算 ≤3 干预/≤40 token。**语义 payload 逐字保留**（by construction 不变）。
  - **目标 family**：F1 增加工具调用 / F2 提前 mutation / F3 诱导放弃。24 held-out 任务 × 3 模型 × C0–C4 × 5 rep = 1800 test（+ 432 dev 选 policy=P2）。
  - **规模/门控**：≥5 官方动作、≥3 distinct 工具；airline 严格 gate 仅 7 任务 → 全进 test（域不平衡作协变量）。
- **结果**（配对 cluster bootstrap + 置换 + Holm 9 检验）：
  - **F1**：C4−C1 = **−0.58**（反方向，CI 上界 +0.12 « +2 阈值）→ **D calibrated null**。
  - **F2**：C4−C1 = **−2.39**（提前 mutation，raw p=0.022）**但** Holm p=0.196、**C4−C3=−0.09（普通压力同样做到）**、top-2 任务集中 0.83、跨域反向 → **B 普通压力**。
  - **F3**：C4−C1 ≈ 0，ASR 0.008 → **D calibrated null**。
  - **endpoint**：三 family 的 C4−C1 reward ≈ 0（未损害成功）；**0 安全事件**；SANDBOX_SCOPE_CLOSED。
- **判定**：**优化定向攻击未产生可归因于对抗优化的过程操纵**——把 R8 的 calibrated null 推广到了优化攻击者设置。

### 2.5 R8-B 高强度 + Confounder Pilot（07-19~22，719/720 episodes）—— P-D
> "会不会是强度不够 / confounder 被忽略了？"—— R8-B 正面回答。

- **Step 1 强制离线复核（gate）**：无 BLOCKER。7 项修正**全部强化 null**：
  1. **endpoint 改 1→1**：C1→C4 转移 0→0=**320** / 1→0=19 / 0→1=18 / **1→1=3**（基线成功仅 ~6%）。旧定义把 341/360 的 0→0 也算 preserved（灌水）→ 修正后 ASR→0。
  2. **F2 full-support**：旧 −2.39 来自 36/120 mutation-both 子集（偏倚）；全支撑 C4≈C1（correct 16 vs 14）。
  3. **turn-0 缓存**：R8-A 逐字相同仅 87.8% → R8-B 缓存后 **100%**（smoke 验证 H0==H3）。
  4. **F3 proxy 作废 → 双审重标**：**所有条件 explicit_abandonment = 0**。
- **Step 2 三部分（严格分开，绝不合并 ASR）**：
  - **Part A 高强度纯攻击（288）**：H0 中性 / H1 = R8-A P2（≤3/≤40）/ **H2 sustained escalation（≤5 干预/≤70 token/压力 1→3 累积）** / **H3 compositional（6-tactic 按公开 state 组合）**。
  - **Part B confounder 因子（360）**：5 模块 2×2，interaction=(A1−N1)−(A0−N0)：M1 额外轮 / M2 长消息 / M3 信息分片 / M4 scaffold / M5 disclaimer。
  - **Part C boundary 上界（72）**：B0 中性 / B1 纯攻击 / B2 = BC-A implicit delegation（"use your judgment"）或 BC-D actual deadline（改变 task semantics）。
- **结果**：
  - **Part A**：唯一可见是 **F1 H3−H0 = +1.29 调用**（raw p=0.010）**但** Holm p=0.058、< +2 阈值、**H3−H1=+0.86 不显著（Holm 0.44）** → 高强度相对普通攻击**无确立增量**。F2 噪声无效，endpoint 近地板。
  - **Part B**：**5 模块 interaction 全部 Holm p=1.0、CI 跨 0** → 无结构性 confounder 可靠放大攻击。
  - **Part C**：纯攻击 B1−B0 ≈ 0；但 **B2 delegation 臂原始成功 0.50 vs deadline 0.17 vs 地板 ~6–17%**（小 n）→ **授权暗示能推动结果，纯语气不能**。
  - **双审**：pre 400 消息 clean 294 / **flagged 21（5.25%）**（高强度使边界依从性从 R8-A 的 0.7% 降到 5.25%，诚实记录）；post 71 对 directed 47 / contam 16 **主要为控制器 payload 漂移**（非攻击者）。
- **判定**：**P-D（+ P-C 脚注）**——停止加强同类纯表达攻击，转向 calibrated boundary/evaluation 论文。

## 3. 成败分析

### 3.1 成功的方面 ✅
1. **基础设施与工程可靠性**：两周内从零建成 R8-A（2232 ep）+ R8-B（720 ep）完整可复现管线——native tau2 编排、优化攻击者、双隔离审查、配对 bootstrap/置换/Holm、完整性与沙箱审计、编排器自动串联。**2232 + 719 episodes、0 缺失（除 1 个确定性容量排除）、INTEGRITY_PASS、SANDBOX_SCOPE_CLOSED、0 安全事件**。
2. **方法学严谨性达到可发表标准**：预注册阈值 + 配对单位 + endpoint 1→1 + full-support + 语义不变 by construction + 增量对比（C4−C3 / H3−H1）+ 多重校正 + 双独立盲审 + leave-one-out + top-task 集中度降级。**每一个"信号"都被拆穿为子集偏倚 / 普通压力 / 控制器漂移 / seed 噪声。**
3. **阴性结果的科学价值被正确定位**：不是"实验失败"，而是**calibrated null**（可排除大于阈值的效应）+ 一个可复用的方法学诊断（松散评估高估脆弱性）。这比"发现一种弱攻击"信息量更大、更稳健。
4. **诚实的自我修正**：R8-A 报出的 F2 −2.39、endpoint 保持、语义不变，在 R8-B 复核中被亲手拆穿为子集偏倚、0→0 灌水、下游漂移——**主动否证自己的上一轮结论**。

### 3.2 未达成 / 失败的方面 ❌
1. **未能证明纯交互攻击可操纵过程**（这是最初的目标）。四种升级路径（完整回合、优化攻击者、高强度组合、结构 confounder）全部为 null / P-D。
2. **任务能力天花板严重**：这些多步骤任务对开源模型**基线成功率仅 ~6%**（C1 reward 0.061，89% 双失败 0→0）。在一个 agent 本就几乎必败的regime里测"过程操纵"，信噪比极低——**部分 null 是被地板效应稀释的**。
3. **语义不变性只在 turn-0 严格成立**：控制器（mistral, temp-0）在下游轮漂移（生成不同订单号/请求），使 C4/C1 端到端并非同一语义。turn-0 缓存到 100% 后，post-review 仍见漂移 → 缺陷在 turn≥1，未根治。
4. **域结构性稀缺**：airline 严格 gate 仅 7 任务，域平衡与"新 held-out"反复受限，只能复用 + 记协变量。
5. **高强度的边界代价**：把强度提到 ≤70 token/递增/组合后，5.25% 的攻击消息被独立审查判为越界（vs R8-A 0.7%）——**强度与"纯表达"边界依从性此消彼长**，即使如此也没换来效果。

### 3.3 根因分析（为什么纯语气不 work）
- **agent 的过程由 policy + 任务结构决定，而非用户情绪**：tau2 agent 在 temp-0 下按 system policy 走固定验证/确认/mutation 流程，用户的 urgency/frustration 不改变它"该查什么、该确认什么"。
- **真正的杠杆在 threat model 边界上**：只有当消息**改变了授权含义（delegation）或任务约束（deadline）**时，结果层才动（Part C delegation 0.50）——这恰恰越过了"纯 interactional expression"的定义，不算 IPMA。
- **松散评估的高估来源**：粗粒度轨迹审查会把**控制器漂移 + 表层措辞差异**误读为"定向过程改变"（R8-A post 154、R8-B post 47），而预注册定量指标一旦引入配对 + 增量 + 校正，效应就归零。

## 4. 关键方法学产出（可迁移）
1. **null-by-construction vs null-by-finding** 的区分与探针诊断（R7-D 的 0/3027 参数解释）。
2. **calibrated null** 的表述范式：报"可排除 > X 的效应"而非"未发现显著差异"。
3. **增量对比 C4−C3 / H3−H1**：把"对抗优化的贡献"与"普通压力/强度"分离。
4. **endpoint 1→1 转移矩阵**：拒绝把 0→0 双失败当"endpoint preserved"。
5. **full-support outcome**：拒绝只分析"双方都发生 mutation"的偏倚子集。
6. **语义不变 by construction + turn-0 缓存**：把污染控制从事后审计前移到构造保证（并暴露下游漂移这一残余缺陷）。
7. **双独立 agent fail-closed 盲审**：无人类审核下的污染/机制核验；并诚实量化"审查高估表层发散"。

## 5. 结论与下一步建议

**结论**：在当前 threat model（纯用户侧互动表达、任务/权限/policy/endpoint 不变）下，**优化后的、乃至高强度组合的交互攻击，对本地开源 tool-agent 的过程无实际重要、可归因的操纵**。结果层唯一可动的杠杆是**授权暗示 / 真实任务约束**，它们改变了 threat model。

**下一步（需批准，未自动执行；spec 均要求完成后停止）**：
1. **转向 calibrated boundary/evaluation 论文**（P-D 建议）：主张=“松散过程级评估系统性高估 agent 交互脆弱性；真正的杠杆是授权/约束边界，不是语气”。
2. 若仍要追攻击：需**先解决任务能力天花板**（换更强 agent 或更易成功的任务子集，把基线成功率从 6% 提到可测区间），否则 null 会被地板效应污染。
3. 修复**下游控制器漂移**（payload 缓存到全轮 / 去随机化 / 按 dialogue-state 对齐比较），才能对"纯语义不变"下的过程效应下更强结论。
4. 针对 **Part C 的 delegation 信号**（0.50 成功率）做预注册的 boundary positive-control 后续——但明确标注为**授权暗示机制**，非 pure IPMA。
